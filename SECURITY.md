# Безопасность

Не публикуйте WB API-токены, финансовые отчёты и персональные данные в issue.
Сообщайте об уязвимостях приватно через GitHub Security Advisory.

При включённом флажке истории агрегированные результаты сохраняются локально в
`.data/history.jsonl` без шифрования. Каталог `.data/` добавлен в `.gitignore` и
не должен коммититься или синхронизироваться в публичные облачные папки. Сам
токен используется только в памяти процесса и не записывается на диск.

Если токен оказался в чате, Git, логе или снимке экрана, немедленно отзовите
его в кабинете WB и создайте новый токен с минимальными read-only правами.
