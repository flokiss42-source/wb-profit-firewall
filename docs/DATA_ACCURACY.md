# Паспорт данных и точности

Приложение не может сделать ответы Wildberries «точнее WB». Оно обеспечивает другое: загружает официальный контракт без обрезания, не подменяет пустые ответы нулями, явно показывает неполные исходные данные и не выдаёт оценку за подтверждённый факт.

## Источники по разделам

| Раздел | Источник WB | Категория токена | Что означает результат |
|---|---|---|---|
| Финансовый аудит | детализация отчёта реализации | Финансы или Статистика для legacy fallback | суммы операций за выбранный период |
| Остатки FBW | `stocks-report/wb-warehouses` | Аналитика | текущий снимок складов WB |
| Карточка товара | `content/v2/get/cards/list` | Контент | название, описание, бренд, характеристики, размеры и фото |
| Поставки FBW | `api/v1/supplies` и товары поставки | Поставки | отгруженное и принятое WB количество |
| Цены | `api/v2/list/goods/filter` | Цены и скидки | базовая цена и скидка продавца |
| Изменение цены | `api/v2/upload/task`, затем статус задания | Цены и скидки с записью | асинхронная операция, подтверждаемая повторным чтением |

## Что контролирует приложение

- Итоговые деньги округляются до копеек.
- Себестоимость сопоставляется сначала по точному баркоду, затем по `nmID`.
- Товар без себестоимости не получает фиктивную прибыль с нулевой закупочной ценой.
- Остатки запрашиваются до официального лимита 250 000 строк; фильтр ограничен 1 000 `nmID`.
- Цены для больших списков запрашиваются пакетами не более 1 000 `nmID`.
- Пустой ответ `204 No Content` означает отсутствие строк у WB, а не ошибку токена.

## Ограничения, которые нельзя скрывать

- Полная формула движения: `остаток на начало + принято − продано + возвраты − списания = остаток на конец + товар в пути`. Без начального снимка приложение показывает потоки, но не заявляет недостачу.
- «Цена продавца после скидки» — управляемая продавцом величина. Итоговая витринная цена может зависеть от скидок WB, акций и WB Клуба.
- Данные обновляются с задержкой на стороне WB. Цены обрабатываются асинхронно и могут попасть в карантин.
- Налог, себестоимость и реклама не возникают из WB автоматически, если соответствующий источник не подключён.

## Проверка перед решением

1. Убедитесь, что период и кабинет правильные.
2. Добейтесь 100% покрытия себестоимостью оборота.
3. Проверьте предупреждения паспорта точности.
4. Для цены дождитесь обработанного задания и повторного чтения значения из WB.
5. Для складского расхождения нужны снимки на начало и конец одного периода.

## Почему без стороннего SDK

SDK не исправляет исходные данные WB и может отставать от контракта. В проекте используется небольшой собственный адаптер, контрактные тесты и официальные endpoints. Это позволяет обновлять конкретный изменившийся метод без замены всей системы.
